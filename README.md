# Agente de Estratégia de Conteúdo & Autoridade (`skill-conteudo-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **Conteúdo & Social Media** com Agentes de IA.

## O que este agente faz

Planeja pautas, calendário editorial e peças de autoridade que atraem decisores sem parecer texto genérico de IA.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-conteudo-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Conte quem é seu público comprador, qual dor ele enfrenta hoje e qual oferta você quer vender. O agente devolve o plano editorial e os temas prontos para publicar.
